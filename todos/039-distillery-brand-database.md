# Distillery/Brand database structure + JSON export

## Context

Currently "brand" is just a text field on each product. The user wants a proper distillery/brand entity with its own database table, metadata, admin CRUD, and JSON export — following the same pattern as whiskies. Distilleries will eventually have their own pages and a map view.

## Requirements

1. **DB migration** (`db/migrations/0018_distilleries.sql`): Create `distilleries` table:
   - `id` TEXT PRIMARY KEY
   - `slug` TEXT UNIQUE
   - `name` TEXT (canonical English name)
   - `name_es`, `name_pt`, `name_en`, `name_ja`, `name_fr` TEXT (localized names)
   - `description`, `description_es`, `description_pt`, `description_en`, `description_ja`, `description_fr` TEXT
   - `country` TEXT (country code or origin id)
   - `region` TEXT
   - `founded` INTEGER (year founded, nullable)
   - `image` TEXT (logo/image path)
   - `website` TEXT (official website URL)
   - `latitude` REAL, `longitude` REAL (geo coordinates, nullable)
   - `created_at`, `updated_at` timestamps

2. **Link products to distilleries**: Add `distillery_id` TEXT column to `products` table (FK to distilleries.id, nullable). Update existing products to link to their distillery by matching brand name.

3. **Seed data** (`data/seed/distilleries.json`): Bootstrap with all known distilleries from existing products (extract unique brands → distilleries)

4. **JSON export** (`scripts/db-export.mjs`): Export distilleries to `src/lib/data/distilleries.json`

5. **Server data** (`src/lib/server/data.ts`): Add `getDistilleryBySlug()`, `getDistilleries()`

6. **Types** (`src/lib/types.ts`): Add `Distillery` interface

7. **Admin CRUD** (`/admin/distilleries`): List, search, create, edit, delete distilleries. Include all metadata fields. Admin can link/unlink products to distilleries.

8. **API endpoints** (`/api/admin/distilleries`): POST/PUT/DELETE

9. **Product admin form**: Add distillery selector dropdown (searchable) to the product edit form

## Acceptance criteria

- `distilleries` table exists in Turso with all columns
- All existing brands are extracted into distillery records
- Products are linked to distilleries via `distillery_id`
- Admin can manage distilleries (CRUD)
- `src/lib/data/distilleries.json` is generated by `npm run data:export`
- `npm run build` succeeds
